# ALgo42

Welcome to the official website repository for **ALgo42** — a student-led AI and Machine Learning club dedicated to fostering innovation, collaboration, and learning.

## About

ALgo42 brings together students passionate about artificial intelligence and machine learning. We organize hands-on projects, workshops, hackathons, and tech events to help members grow their skills and connect with like-minded peers.

## Pages

The website includes the following pages:

- [`index.html`](index.html) — Home page with an overview of the club
- [`structure.html`](structure.html) — Club structure and team information
- [`events.html`](events.html) — Upcoming and past events
- [`gallery.html`](gallery.html) — Photo gallery from club activities

## Getting Started

To view the website locally, simply open any of the HTML files in your web browser:

```bash
# Clone the repository
git clone https://github.com/thedv-dev/Algo42.git

# Open the home page in your browser
open index.html
```

Alternatively, you can use a local development server:

```bash
# Using Python
python -m http.server 8000

# Then visit http://localhost:8000 in your browser
```
